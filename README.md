# fastapi-agent-server

A small FastAPI service that forwards prompts to a LangChain agent backed by Ollama.

## Requirements

- Python 3.13 or newer
- `uv`
- Ollama
- The Ollama `mistral` model, unless another model is configured

Install and prepare the Python environment:

```powershell
uv sync
```

Install and start Ollama, then download the default model:

```powershell
ollama pull mistral
```

Set `OLLAMA_MODEL` to use a different installed model.

## Run the server

Start the API from the project root:

```powershell
uv run python main.py
```

The server listens on `http://localhost:8000`. FastAPI's interactive documentation is available at `/docs`.

## Send a request

The `POST /home` endpoint expects an agent name and prompt:

```powershell
Invoke-RestMethod `
	-Uri http://localhost:8000/home `
	-Method Post `
	-ContentType "application/json" `
	-Body '{"agent":"general","prompt":"Explain generative AI in 50 words."}'
```

The `general` agent returns the final response generated by the model. It follows output formats requested in the prompt, including JSON.

## Run the tester

Create `file_input.txt` in the project root with the text to classify, then run:

```powershell
uv run python tester.py
```

The tester sends the file contents to the `general` agent and prints the returned `Category` value when the response is JSON.

## Project layout

```text
main.py                 FastAPI application and /home route
agents/general.py       Ollama-backed LangChain agent
call_checker/main.py    Agent dispatch logic
tester.py               Sample classification client
file_input.txt          Local tester input, created by the user
```
